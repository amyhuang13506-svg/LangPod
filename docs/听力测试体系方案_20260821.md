# 听力测试体系方案（2026-08-21）

> 状态：待确认。确认后按阶段动工。

## 一、背景与依据

- 结算卡测试题数据（8/20，新版满覆盖首日）：65 人看到卡 → 34 人做题（52%）→ 32 人做完（94%）。**"测"是已验证的强钩子**，参与量是旧练习功能（词义配对 3 人/天）的十倍。
- 每日 AI 播客脚本自产 → 出题零成本、Easy/Medium/Hard 天然分级、每天自动一套新题。这是供给优势。
- 新用户 30 秒流失：raw 播放 45-50% 在 30s 内离开；新用户落地即面对"长内容 feed"是重要原因之一。
- 现 onboarding 让用户自己选级别——新用户其实不知道自己该选什么。

## 二、总体设计：听力测试的三个入口 + 一个后手

```
入口 1  新用户首弹：初级听力测试（分级测试式开局）
入口 2  首页顶部三分类：首页 / 学习 / 听力测试
入口 3  每日任务第一格：今日听力测试（与压轴听集任务用不同集）
后手    首页默认落点做成服务器配置，数据支持后一键翻转为「听测优先」
```

## 三、Pipeline：episode 出题（先行，第 0 步）

- `generate_daily` 新增出题步：从当日每集 script 的**前 ~15 行**（对应音频前 ~90 秒）
  生成 3 道英文单选（考大意，六语言解析），逻辑与 `generate_raw_quiz.py` 同款。
- 输出：`episodes/{id}/quiz.json` 旁挂（App 从 episode 音频 URL 派生，同 raw 模式）。
- **存量回填**：全部已上线集（每级 62 集 × 5 语言的 zh 主脚本）回填，测验页
  才有"往期"供给。幂等脚本，成本与 raw 回填同级（~¥15）。
- 出题只基于前 90 秒：保证「听 90 秒就能作答」，测验轻量化的根基。
- ⚠️ 改完 scp 到服务器（pipeline-server-sync-gotcha）。

## 四、入口 1：新用户首弹（替代新用户首次的今日计划弹窗）

- 触发：完成 onboarding 后首次落到首页，弹「测测你的听力水平」卡（仅一次；
  老用户不受影响，仍走今日计划弹窗）。
- 流程：播当日 Easy 集前 90 秒（结算卡同款浅色卡内嵌播放条）→ 3 题 →
  得分页：「你答对 X/3，适合从『中级』开始」→ 主 CTA「去今日听力测试」
  （深链听测页）+ 次 CTA「先逛逛」。
- 分级建议规则（MVP）：3/3 → 建议 Medium；2/3 → 保持 Easy→Medium 按用户
  onboarding 所选；≤1 → Easy。仅"建议+一键切换"，不强改用户已选级别。
- 可跳过（右上 ✕），跳过则回落今日计划弹窗逻辑。

## 五、入口 2：首页三分类

- 首页顶部 segment：**首页（原声 feed）/ 学习（教学播客+句型+课程）/ 听力测试**。
- 现有内容归位：原声视频/探索 → 「首页」；级别播客列表、今日句型、场景课 → 「学习」。
- **默认落点由服务器配置**（`index.json` 或全局 config 加 `default_home_segment`
  字段，App 启动读取，缺省 = 首页）。翻转「听测优先」时只改服务器配置，不发版。

### 听力测试页

- 今日测验卡（按用户级别取当日集；做完显示得分徽章）。
- 其余两级的当日测验（次要位置，可跨级挑战）。
- 往期成绩单：日历/列表式，展示每日得分（🟢3/3 🟡2/3 ⚪未做）——
  成绩单即"感觉学到了"的可视化，后续可做分享卡。
- 测验流程复用结算卡的固定尺寸答题卡组件（RawSessionSummaryView 的 quiz 部分
  抽成共用组件），得分页 + 生词入本。
- 往期测验 Free/Pro：今日免费，往期 Pro（与句型历史一致）。

## 六、入口 3：每日任务第一格

- 第一格固定为「今日听力测试」（约 2 分钟：90 秒 + 3 题），深链听测页今日卡。
- 压轴「听一集学习播客」保留，**两格用不同集**（用户 8/21 拍板）：
  测验用当日第 1 集，听集任务深链当日第 2 集；当日只有 1 集时听集任务
  回退到最新未听集。
- 原第一格的图文轻任务（句型图文卡/词汇小课堂）移入机动池。

## 七、后手：首页翻转的数据门槛

跑两周后对比（友盟自定义留存 + 事件）：

- 做过听力测试人群 vs 只看视频人群的 D1；
- 听测页周活跃 uv / 首页 uv 占比；
- 新用户首弹完成率 vs 跳过率。

若测题人群 D1 明显占优（≥5pp）且首弹完成率 >50% → 服务器配置翻转
`default_home_segment = listening_test`，完成「学习主基调」改版落锤。

## 八、埋点（需友盟注册，配额 49/100 → 53/100）

- `listening_test_start`（source: onboarding_popup / home_tab / daily_task / raw_summary）
- `listening_test_complete`（correct_count, level）
- `onboarding_test_skip`
- `home_segment_switch`（segment）

## 九、决策记录

- 两格不同集（8/21 用户拍板）。
- 首页翻转不即时做，走配置 + 数据门槛（本方案核心保守点：
  用已验证的留存人群换未验证入口的风险不可逆，配置化让翻转零成本可回滚）。
- 新用户首弹测试替代的是"新用户首次的今日计划弹窗"，不叠加弹窗
  （Day 0 改造"只弹一个"的原则不破）。
