2. サービスの説明

2.1 核心機能

Castlingoは英語のリスニング学習アプリであり、選ばれたポッドキャスト内容を通じてユーザーの英語のリスニング能力向上を助けます。私たちの核心機能は次のとおりです：

  • レベル別英語ポッドキャスト内容（初級、中級、上級）
  • 五回反復学習法（英語原音 × 3 + 二言語字幕 + 日本語翻訳）
  • スマート語彙管理（新しい単語の保存、記憶のトラッキング）
  • インタラクティブ練習（語義のペアリング、単語をつなげて文を作成）
  • 学習記録と統計（連続記録、達成バッジ）

3. サブスクリプションサービス条款

3.1 サブスクリプションプラン

Castlingo Proは次のサブスクリプションプランを提供します：

  • 年払いプラン：¥298/年（約 ¥24.8/月）、3日間の無料試用が提供される可能性があります
  • 月払いプラン：¥48/月、3日間の無料試用が提供される可能性があります

実際の価格はApple App Storeに表示される価格に準じており、地域や為替変動により異なる場合があります。

3.2 無料試用

一部のサブスクリプションプランでは無料試用期間が提供される可能性があります。注意してください：

  • 無料試用期間は通常3日間です
  • 試用期間終了後、試用期間終了前に少なくとも24時間前にサブスクリプションをキャンセルしない限り、自動的に有料サブスクリプションに移行します
  • 試用期間中のキャンセルにより費用は発生しません
  • 各Apple IDは一度のみ無料試用を楽しめます
  • 未使用の無料試用期間はサブスクリプション購入後に自動的に無効になります

3.3 自動更新

重要な注意：Castlingo Proは自動更新サブスクリプションサービスです。サブスクリプションは各請求サイクルの終了時に自動的に更新されます。現行のサイクルが終了する少なくとも24時間前にキャンセルしない限り。
  • 更新費用は現行のサブスクリプション期間終了前24時間以内にあなたのApple IDアカウントから差し引かれます
  • 更新価格は最初にサブスクリプションしたときの価格と同じです。価格変更を事前に通知する場合を除いて
  • 価格変更時には通知され、変更価格が有効になる前にキャンセルする機会が与えられます

3.4 サブスクリプションのキャンセル

サブスクリプションはいつでもキャンセルできます。方法は以下の通りです：

  1. iPhoneの「設定」アプリを開く
  2. Apple ID（トップの名前）をタップする
  3. 「サブスクリプション」をタップする
  4. Castlingoを見つけて「サブスクリプションのキャンセル」をタップする

キャンセル後、すでに支払った期間が終了する前にPro機能を利用し続けることができます。期間終了後、あなたのアカウントは無料版に戻りますが、学習データは失われません。

3.5 返金ポリシー

すべての購入と返金はAppleによって処理されます。返金を申請する場合は、Appleサポートに直接連絡するか、 reportaproblem.apple.com でリクエストを送信してください。私たちは直接返金を処理することはできません。
