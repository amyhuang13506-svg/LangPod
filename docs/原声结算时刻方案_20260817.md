## 一、背景：8/17 数据诊断结论

1. **Day 0 改造有效**：首集完成率从老版本的 10.6%~18% 抬到新版的 25%~34%（约 8/5 起生效），但 **D1 留存纹丝不动**（新用户 18-24%，活跃用户 24-28%）→ 瓶颈已从"激活"转移到"回访动机"。
2. **原声视频是全 app 消费人数第一的内容**：8/15 独立用户 raw_play_start 227 > episode_play_start 185 > lesson_open 178。用户在用脚投票，验证了"用真实内容学英语"的定位。
3. **看原声的人留存更好**：raw 播放者 D1 稳定在 24-33%（均值 ~28%），高于大盘。
4. **两个漏点**：
   - 原声路径没有任何"结算/反馈"时刻——用户看一半退出，什么都没发生。学习发生了但完全不可见（"感觉学到了"缺失）。
   - 原声 30 秒流失过半：raw_play_start 227 → raw_listen_30s 113。

**核心判断**：用户把大部分时间花在一条没有反馈闭环的路径上，这是"消费在涨、留存不涨"的主要解释。本方案给原声路径装上与教学播客完成页对等的"结算时刻"。

## 三、改动一：退出即结算卡（优先级最高）

### 触发

- 触发点：`RawPodcastPlayerView` 关闭时（用户下拉/点关闭按钮）。**先叠结算层再 dismiss**，不做"关闭后在 feed 页弹卡"（时序不可控）。
- 达标条件：本次会话 `listenAccumSeconds >= 180`（3 分钟，走远程配置可调）。
- 不触发：
  - 会话 < 180s → 直接关闭，无打扰；
  - 同一天第 2 次及以后达标退出 → 降级为轻量 toast（"+X 分钟 · 今日累计 Y 分钟"），不弹大卡；
  - 内部叠层（paywall sheet、字幕 sheet）弹出导致的 onDisappear 不算关闭——只挂在显式关闭手势/按钮上。

### 卡片内容（数据全部来自现有字段）

```
🎉 大数字动效（参考完播庆祝）
+8 分钟真实语料听力        ← controller.listenAccumSeconds
划过 2 个生词              ← 本次会话 addWord(sourceLabel:"raw_podcast") 计数
今日累计 14 分钟           ← TaskEngine 原声任务累计秒数
🔥 连续第 4 天             ← 现有 streak
[若本次会话让「原声听5分钟」任务达标] 任务打勾动效
------------------------------------
CTA 主：测测听懂了多少（→ 改动二的 3 题，无题时隐藏）
CTA 次：继续听 / 关闭
```

- 视觉与完播庆祝同一套语言（弹性缩放 + 震动），成本低且体验一致。
- 结算层点击空白处可直接关闭，绝不强制停留。

### 实现落点

- `RawAudioController` 已有 `listenAccumSeconds`（0.5s 粒度、已过滤 seek），直接读。
- 会话划词计数：`RawPodcastPlayerView.addWord` 处加会话内计数器（挂在 controller 上，随 tearDown 清零）。
- streak / 任务数据：`DataStore` / `TaskEngine` 现有接口。

### 埋点（需同步在友盟后台注册，配额 45/100 → 47/100）

- `raw_summary_view`（params: listened_seconds, words_saved, is_first_today）
- `raw_summary_cta`（params: action = quiz / continue / close）

## 四、改动二：原声理解题（3 题）

### Pipeline 侧（服务器）

- 新脚本 `generate_raw_quiz.py`，插在 transcript 清洗+翻译之后：
  - 输入：清洗后的 transcript（截取用户最可能听到的前 ~10 分钟）；
  - GPT 生成 3 道单选题：`{q_en, options[3], answer_idx, explain}`，题目考"听懂了大意/关键信息"，不考语法；
  - `explain` 按语言字典存（`{"zh-Hans": "...", ...}`），与 i18n-foundation 分支的多语言链路对齐，MVP 先只产 zh-Hans，其余语言走现有 localize 批处理补；
  - 输出 OSS：`raw/{podcast_id}/quiz.json`；生成失败非致命（try/except，同 extract_patterns 惯例）。
- 存量：不回溯老内容，新内容自动带题;结算卡上无题则隐藏 CTA。
- ⚠️ 改完必须 scp 到服务器（见 pipeline-server-sync-gotcha），否则凌晨 cron 用旧脚本。

### App 侧

- 结算卡 CTA「测测听懂了多少」→ 3 题卡片流：选项点击 → 绿勾/红叉 + 震动 + 一行解析 → 3 题完 → 小结（"3/3 你真的听懂了硅谷人在说什么"+ 庆祝动效）。
- quiz.json 懒加载：进入播放页时不拉，点 CTA 时才 fetch（失败则 CTA 消失，无报错打扰）。
- **免费开放，不设 Pro 墙**——这个功能的目的就是制造"学到了"的感觉，是留存杠杆不是变现杠杆。
- 会话 < 300s 不出题 CTA（听太少答不了）。

### 埋点

- `raw_quiz_start`、`raw_quiz_complete`（params: correct_count）
