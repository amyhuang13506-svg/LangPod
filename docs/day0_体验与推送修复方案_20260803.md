## 一、数据结论（8-02，友盟自定义事件首个完整统计日）

**激活漏斗（独立用户数）：**

| 步骤 | 人数 | 转化 |

| first_episode_complete | **15** | **10.6%** |

**播放漏斗（全体用户）：**

| 步骤 | 人数 | 上一步转化 |
|---|---|---|
| episode_play_start | 93 | — |
| listen_30s | 76 | 82% ✅ |
| episode_round1_complete | 70 | 75% ✅ |

- **用户不是在开头流失的**：愿意点播放、听得完第 1 遍。流失集中在第 2 遍及以后的重复播放（当天 episode_abandon 65 人）。
- 完成页 / 生词卡 / 任务打勾 / streak 全部锁在全遍数之后 → 大多数用户从未见过奖励闭环（vocabulary_save 全天仅 47 人）。
- 对照组：YouTube 原声 92 人开播 → 60 人听到结尾（65%），完成率约为 5 遍模式两倍。
- 付费墙时机过早：124 人看到（人均 3.2 次）vs 31 人完整听完一集；17 人进购买页 → 4 单。
- push_opened 全天 **1 人**（原因见第四节，推送系统实际停摆）。

## 二、改动 A：完成结构改革（第 1 遍 = 完成）

**原则：奖励闭环挪到第 1 遍结束，重复遍数从"门槛"变"选项"。**

1. 第 1 遍英语听完 → 立即触发完成页（生词卡 + 累计统计 + 任务打勾 + streak +1）。
2. `episode_complete` 判定同步改为第 1 遍完成（`first_episode_complete` / Adjust 信号跟着受益）。
3. 完成页主 CTA 三个：
   - **「再听加深」**（进入第 2-N 遍循环，保留磨耳朵法；完成页顶部显示"已听 1/5 遍"）
   - **「下一集」**
   - **「保存生词」**（现有）
4. 播放页遍数标签保留；处于第 2+ 遍时不再重复弹完成页（本集当日只弹一次）。
5. 适用所有用户（方案 A1）。备选 A2：仅新用户前 3 集生效，老用户维持 5 遍门槛 —— 若担心改变产品心智可选 A2，但数据显示老用户同样被 5 遍耗损，推荐 A1。

**不改**：音频结构、pipeline、免费每日集数限额。

## 三、改动 B：弹窗顺序改造（去掉三连弹）

现状：onboarding 完成瞬间 = 推送系统弹窗 → ATT 弹窗 → 1.5s 后每日任务弹窗（压在系统弹窗下面）。

| 弹窗 | 现在 | 改为 |
|---|---|---|
| 每日任务（今日计划） | 落地 1.5s 后 | **不变**，且独享落地时刻 |
| 推送权限 | 落地立即系统弹窗 | **首集完成页**：先弹自制铺垫卡（"明天新内容上线时提醒你？允许 / 暂不"），点「允许」才触发系统弹窗；点「暂不」不消耗系统机会，streak ≥3 天时可再问一次 |
| ATT 跟踪 | 排在推送弹窗后 | **第二次冷启动**（didBecomeActive 现有逻辑天然覆盖，删掉 onboarding 处的调用即可）。Adjust 设备级归因晚一天，SKAdNetwork 不受影响 |

新增埋点：`push_permission_result`（granted: yes/no + source: first_complete/streak3），授权率从此可测。
（服务器 token 数据显示当前授权率约 60-72%，1857 台可推设备 —— 触达面没问题，问题在下面。）

## 四、改动 C：服务器端推送修复（与发版无关，立即生效）

**排查结论（2026-08-03 上服务器查实）：**

1. **早 7:30 推送自 7-26 起停摆 9 天**（最后一次成功 7-25，发 833 台）。
   根因链：IPRoyal 住宅代理**欠费**（`402 Payment Required`）→ YouTube 管线每天 0 条新视频 → 推送队列空 → flush 无货可发。
2. **副作用更大：首页主内容（YouTube 原声）9 天没有更新**（master 停在 317 条）。
   7-30 后 DAU 从 451 跌到 323、新增回落，时间点吻合。
3. **下午 5 点集数推送从未存在**：crontab 只有注释没有任务，且 generate_daily.py 从未调用 enqueue_episode。
4. GPT 播客管线正常（每天 6 集，0 错误）；晚 8 点本地推送逻辑在但点击≈0，待 intent 数据积累后单独优化文案。

**修复项：**

- C1【用户操作，最急】IPRoyal 充值（pay-as-you-go $1.75/GB，geo.iproyal.com 账号）→ 内容 + 早推送同时复活。
