2. 服務說明

2.1 核心功能

Castlingo 是一款英語聽力學習應用程式，透過精選播客內容幫助使用者提升英語聽力水平。我們的核心功能包括：

  • 分級英語播客內容（初級、中級、高階）
  • 五遍迴圈學習法（英語原音 × 3 + 雙語字幕 + 中文翻譯）
  • 智慧詞彙管理（生詞儲存、記憶追蹤）
  • 互動練習（詞義配對、連詞成句）
  • 學習記錄與統計（Streak、成就徽章）

3. 訂閱服務條款

3.1 訂閱方案

Castlingo Pro 提供以下訂閱方案：

  • 年付方案：¥298/年（約 ¥24.8/月），可能提供 3 天免費試用
  • 月付方案：¥48/月，可能提供 3 天免費試用

實際價格以 Apple App Store 顯示的價格為準，可能因地區和匯率變化而有所不同。

3.2 免費試用

部分訂閱方案可能提供免費試用期。請注意：

  • 免費試用期通常為 3 天
  • 試用期結束後，除非您在試用期結束前至少 24 小時取消訂閱，否則將自動轉為付費訂閱
  • 試用期內取消不會產生任何費用
  • 每個 Apple ID 僅可享受一次免費試用
  • 未使用的免費試用期在購買訂閱後將自動失效

3.3 自動續費

重要提醒：Castlingo Pro 為自動續費訂閱服務。訂閱將在每個計費週期結束時自動續費，除非您在當前週期結束前至少 24 小時取消。
  • 續費費用將在當前訂閱期結束前 24 小時內從您的 Apple ID 賬戶扣除
  • 續費價格與您初次訂閱時的價格相同，除非我們提前通知價格變更
  • 價格變更時，您將收到通知並有機會在新價格生效前取消

3.4 取消訂閱

您可以隨時取消訂閱，方法如下：

  1. 開啟 iPhone 的"設定"應用
  2. 點選您的 Apple ID（頂部的姓名）
  3. 點選"訂閱"
  4. 找到 Castlingo 並點選"取消訂閱"

取消後，您仍可在當前已付費週期結束前繼續使用 Pro 功能。週期結束後，您的賬戶將恢復為免費版，但您的學習資料不會丟失。
